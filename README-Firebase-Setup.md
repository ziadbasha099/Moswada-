# إعداد صفحة التنزيلات ولوحة المدير (Firebase)

هذه الميزة الجديدة تتكوّن من 3 صفحات:

- **downloads.html** — صفحة عامة يراها كل الزوار، تعرض أزرار تحميل منظّمة في مجلدات، مع بحث.
- **admin.html** — صفحة مخفية ومحمية بتسجيل دخول حقيقي (وليس كلمة مرور مكتوبة في الكود)، منها تُضيف زر تحميل جديد بإدخال (العنوان + رابط MediaFire).
- **firebase-config.js** — ملف الإعدادات المشترك بينهما.

لأن الموقع الحالي بلا "باك اند"، الحل المستخدم هنا هو **Firebase** (مجاني للاستخدام بهذا الحجم) عبر خدمتين:
1. **Firestore** — قاعدة بيانات تُخزَّن فيها الروابط، وتُقرأ لحظياً من صفحة `downloads.html` لكل الزوار.
2. **Authentication** — لحماية `admin.html` بتسجيل دخول حقيقي (بريد + كلمة مرور)، بدل فحص كلمة مرور داخل كود الجافاسكربت (وهو غير آمن لأن أي زائر يقدر يقرأه من المتصفح).

## الخطوات

### 1) أنشئ مشروع Firebase
- اذهب إلى https://console.firebase.google.com
- Add project → أعطه اسماً (مثلاً moswada) → أكمل الخطوات.

### 2) فعّل Firestore
- من القائمة الجانبية: **Build → Firestore Database → Create database**.
- اختر **Start in production mode** ثم اختر أقرب موقع خادم لك.

### 3) اضبط قواعد الأمان (Rules)
داخل Firestore → تبويب **Rules**، استبدل المحتوى بهذا:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /downloads/{docId} {
      allow read: if true;
      allow write: if request.auth != null;
    }
  }
}
```

هذا يعني: أي شخص يستطيع **قراءة** الروابط (لهذا تظهر لكل الزوار في `downloads.html`)، لكن **الكتابة/الإضافة/الحذف** لا تتم إلا من حساب مسجّل دخول (أي أنت فقط عبر `admin.html`).

### 4) فعّل تسجيل الدخول بالبريد وكلمة المرور
- من القائمة الجانبية: **Build → Authentication → Get started**.
- من تبويب **Sign-in method**، فعّل **Email/Password**.
- من تبويب **Users → Add user**، أنشئ حساب المدير (بريدك الإلكتروني + كلمة مرور قوية). هذا هو الحساب الذي ستسجّل به الدخول في `admin.html`.

> يمكنك إنشاء أكثر من حساب مدير بنفس الطريقة إن احتجت.

### 5) انسخ إعدادات المشروع إلى الموقع
- من **Project settings** (أيقونة الترس) → **General** → انزل إلى **Your apps** → اضغط أيقونة الويب `</>` لإنشاء تطبيق ويب جديد.
- سيعطيك كائن `firebaseConfig`. انسخه والصقه داخل ملف **firebase-config.js** في مكان القيم الحالية (YOUR_API_KEY... إلخ).

### 6) ارفع الملفات على الموقع
ارفع هذه الملفات كلها في نفس مجلد `index5.html`:
- `downloads.html`, `downloads.js`
- `admin.html`, `admin.js`
- `firebase-config.js`
- `downloads-admin.css`

### 7) جرّب
- افتح `admin.html`، سجّل دخول بحساب المدير، أضف رابط MediaFire.
- افتح `downloads.html` (من نفس الجهاز أو جهاز آخر) — يجب أن يظهر الرابط فوراً بلا أي تعديل كود.

## ملاحظات أمان
- لا تشارك رابط `/admin.html` علناً — مع ذلك هو محمي فعلياً بتسجيل الدخول، فحتى لو عرفه أحد لن يستطيع الدخول بدون بيانات حساب المدير.
- تأكد أن قواعد Firestore مضبوطة كما في الخطوة 3، وإلا سيستطيع أي شخص الكتابة في قاعدة البيانات.
- إن أردت تقييد الإضافة على بريد إلكتروني واحد فقط، يمكن تعديل قاعدة الكتابة إلى:
  `allow write: if request.auth != null && request.auth.token.email == "your-admin@email.com";`
